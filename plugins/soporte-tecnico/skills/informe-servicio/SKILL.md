# Informe de servicio

Estructura corta (una página):
1. **Equipo:** tipo y modelo (sin datos personales en repos públicos).
2. **Fecha y quién atendió.**
3. **Síntoma reportado** (con las palabras del cliente).
4. **Qué se encontró.**
5. **Qué se hizo** (en orden).
6. **Resultado y qué quedó sin probar.**
7. **Recomendaciones** (limpieza periódica, respaldo, cambio de pieza).

Reglas: lenguaje simple para el cliente; nada de culpar; si se cambió una pieza, anotarla; los datos reales del cliente se guardan **fuera** de repos públicos. Los ejemplos usan clientes inventados.
