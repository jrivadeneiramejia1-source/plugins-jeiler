# aprender-jeiler

- Skill `modo-aprendizaje`: explica con palabras simples y un ejemplo de la vida diaria.
- `/glosario <palabra>`: explica y guarda una fila en tu hoja «Glosario Jeiler» de Drive (la busca por nombre; no la crea sola). Si la palabra ya está, explica menos.
- `glosario/GLOSARIO.md`: copia de inicio en GitHub. La versión viva es la hoja de Drive.

Necesita el conector de Google Drive y Google Sheets.

Instalar: `/plugin install aprender-jeiler --marketplace jrivadeneiramejia1-source/plugins-jeiler`
