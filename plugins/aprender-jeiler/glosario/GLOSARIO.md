# Glosario (copia de inicio)

La versión viva está en tu hoja «Glosario Jeiler» de Google Drive. Esta es solo una copia de arranque, sin datos personales.

| Palabra | Qué es | Ejemplo |
|---|---|---|
| n8n | Programa para unir apps y automatizar tareas sin programar mucho. | Cuando llega un mensaje de WhatsApp, n8n lo guarda en una hoja de cálculo solo. |
| webhook | Una dirección web que avisa a otro programa cuando pasa algo. | Es como el timbre de tu casa: alguien lo toca y tú te enteras al instante. |
| API | Forma en que un programa le pide cosas a otro. | El mesero lleva tu pedido a la cocina y te trae la comida: la API es el mesero. |
| rama (branch) | Copia paralela de tu proyecto para probar cambios sin dañar la versión buena. | Haces un borrador en otra hoja antes de pasarlo al documento final. |
| PR (pull request) | Pedido para unir los cambios de una rama a la versión principal, para que alguien los revise. | Entregas el borrador al jefe y él dice «sí» antes de pegarlo en el documento final. |
