# apps-jeiler

Comandos para tus apps en GitHub y Cloudflare.

- `/estado-repos [carpeta]`: tabla con rama, cambios sin guardar y commits sin subir de cada repo. Solo lee.
- `/antes-de-subir`: revisa claves, datos personales, pruebas y licencias antes de subir una rama.
- `/actualizar-drive`: actualiza tu copia en Drive solo si lo escribes tú, y primero te muestra qué cambiaría.
- Agente `auditor`: busca claves expuestas y fallas básicas. Solo lee.

Instalar: `/plugin install apps-jeiler --marketplace jrivadeneiramejia1-source/plugins-jeiler`
