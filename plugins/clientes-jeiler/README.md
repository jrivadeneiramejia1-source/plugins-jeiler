# clientes-jeiler

Textos para tus clientes de servicios. No guarda ni pide datos reales; los ejemplos usan «Cliente».

- `/cotizar`, `/briefing`, `/acta-entrega`, `/mensaje-cliente` (cobro, avance, entrega, demora).
- No inventan precios ni garantías: te preguntan.
- Lo legal es buena práctica, no asesoría: que un abogado lo confirme.
- Usan las skills de `servicios-skills-jeiler` si están instaladas.

Instalar: `/plugin install clientes-jeiler --marketplace jrivadeneiramejia1-source/plugins-jeiler`
