# agentes-ia-jeiler

Para crear agentes y bots gastando poco.

- `/elegir-api-gratis <necesidad>`: hasta 3 opciones con su límite. Los límites van marcados [P] porque cambian.
- `/costo-estimado <tarea>`: costo por vez, día y mes antes de correr algo.
- `/nuevo-agente <qué hace>`: plantilla con límites y seguridad.

Usa las skills de `agent-skills-jeiler` si están. Nunca pide claves.

Instalar: `/plugin install agentes-ia-jeiler --marketplace jrivadeneiramejia1-source/plugins-jeiler`
